学习记录备份

GitHub Pages 本身不会把电脑和手机的 localStorage 自动同步。你可以把学习记录导出为 JSON，再在另一台设备导入。

安装到手机主屏幕

iPhone / Safari

打开网站 → 点“分享” → 选择“添加到主屏幕”。之后可以像 App 一样从桌面打开。

Android / Chrome

打开网站 → 浏览器菜单 → 选择“添加到主屏幕”或“安装应用”。

学习记录仍然保存在当前浏览器；需要换设备时，用上面的“导出 / 导入”功能迁移。
